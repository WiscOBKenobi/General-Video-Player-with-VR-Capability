## 隐私和安全检查

- 原视频只通过用户主动选择／拖放取得 File 和临时 Blob URL。生产代码没有写回文件、转码、上传、网络请求、遥测或播放记录存储。
- 生产资源全部为本地相对引用；CSP 禁止网络连接，媒体仅允许 Blob，脚本仅允许本站资源，禁止 object、base 和表单提交。
- 文件名通过 textContent 展示，不进入 HTML、脚本、网页标题或导航 URL。构造的标记型恶意文件名被按普通文本显示。
- 切换与终止会取消旧监听器、停止并卸载媒体、撤销 Blob URL；终止额外清除界面信息与当前图形纹理。pagehide 执行清理，页面不会续播。
- 无痕范围仅为播放器应用层；不保证清除浏览器／操作系统历史、交换文件或内存物理残留。恶意媒体的底层解码安全依赖浏览器自身。
- 发布文件检查未命中常见高置信凭据模式或本机绝对路径。此检查结合人工文件审阅，不能证明任意形式的秘密绝对不存在。
- `npm audit` 对当前锁定开发依赖报告 0 个已知漏洞（2026-10-07）；这是特定时点的已知漏洞检查。
