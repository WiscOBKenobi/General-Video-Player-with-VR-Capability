# General Video Player with VR Capability

用 Edge 或 Chrome 打开本目录的 `index.html`，选择或拖入本地视频即可。保留同目录其他文件；无需安装、账号或联网。

- 常见左右分屏 VR180：先选「VR 视频」，再选「180°」「左右分屏」「左眼」。
- 360°全景：先选「VR 视频」，再选「360°」，再按片源选择单幅、左右或上下分屏。
- 普通二维视频：默认「普通视频」即可，无需分屏设置。
- VR 模式拖动环视、滚轮缩放；单击画面或空格播放／暂停，双击或 F 切换全屏，R 回正。
- 倍速可输入 1.05、1.1 等小数，回车应用；范围 0.25～4。
- 多选或批量拖放添加到会话列表，点击列表切换。「清空列表与播放」或「■ 终止」清空整个列表、卸载视频并清除画面、文件名和进度，不删除原文件。
- 全屏控制栏半透明悬浮，鼠标离开控制栏且静止约一秒时自动隐藏；移动鼠标或按键重新显示。

播放器不上传视频、不持久化播放记录，列表仅当前页面保留，刷新或关闭即清空、不压缩或改写原文件。浏览器、系统文件选择框及操作系统自身的记录不受网页控制。显示会按窗口和 VR 视角进行采样；这不是对原文件重新编码。

支持等距柱状 180°／360°、普通平面视频；不支持鱼眼、EAC、立方体投影、WebXR 或转码。浏览器需支持片源编码并启用图形加速；4K／8K性能、HDR和不同音轨表现依设备而异。
